# Walmart Sales & Profit Analysis Dashboard

## Project Overview
This project is an interactive Sales and Profit Analysis Dashboard created using Power BI. 
The dashboard helps business stakeholders understand sales performance, profit trends, 
and category-wise performance.

## Objective
The main objective is to design an interactive dashboard that provides useful business 
insights through KPIs, charts, and filters.

## Dataset
The dashboard uses a Walmart Sales and Financial dataset.

### Main Columns
- Order ID
- Order Date
- Ship Date
- Geography
- Category
- Product Name
- Sales
- Quantity
- Profit

## Tools Used
- Power BI Desktop
- Microsoft Excel
- DAX

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Sales Growth %
- Monthly Sales Trend
- Monthly Profit Trend
- Sales by Category
- Profit by Category
- Year Slicer
- Geography Slicer
- Category Slicer

## Key Analysis
The dashboard provides:
- Monthly sales trend analysis
- Monthly profit trend analysis
- Sales comparison across categories
- Profit comparison across categories
- Interactive filtering by year, geography, and category

## Project Files
- `Walmart_Dashboard.pbix` – Power BI dashboard
- `Walmart_Dataset.xlsx` – Dataset used for analysis
- `Walmart_Dashboard_Task_4_Final.pptx` – Project presentation
- `Dashboard_Screenshot.png` – Dashboard screenshot

## Conclusion
The Power BI dashboard transforms raw Walmart sales data into an interactive 
business intelligence report.
